## What an Unlucky Day 攻略：探す前にルートを決める

What an Unlucky Dayで最も難しいのは、個々のアイテムを見つけることではありません。店の看板、屋台、水、人混みが詰まった広く開けた通りの風景全体で、整理された状態を保つことです。このレベルは1フロア構成なので、階段や屋内の部屋が与えてくれるリセットがありません。そのため、速度よりも計画が重要です。以下の検証済みルートは、メインストーリーの全アイテムに加えてAfroditeのボーナス拾得物をカバーし、ほとんどのコンプリート狙いがつまずく任意の風船回収も示します。

この攻略は、[Casual Game Guidesの第7章の詳細](https://casualgameguides.com/walkthroughs/lost-and-found-co/chapter-7-what-an-unlucky-day-walkthrough)と[Into Indie Gamesの第1〜7章攻略](https://intoindiegames.com/walkthroughs/lost-and-found-co-walkthrough-chapters-1-7/)で記録されているアイテムリストと場所に従っています。Casual Game Guidesではこのステージを第7章として扱っており、Into Indie Gamesでは最初の7章をまとめたガイド内で扱っています。2つのガイドが同じアイテムについて異なる隠し場所を説明している場合は、どちらも確認できるよう両方を記載しています。

## What an Unlucky Dayの全アイテムリスト

ステージの片側から作業し、時計回りに回ります：通り、路地、水辺、屋台、店先。この1つの習慣が、5つのゾーンを中途半端に探してどれも覚えていないという典型的な失敗状態を防ぎます。

| アイテム | 探す場所 |
|---|---|
| ハト（Pigeon） | 右側にあるボードゲーム店の等身大パネル看板。マジシャンの人だかりを目印にする |
| お気に入りの携帯電話（Favorite Phone／オレンジ色の携帯） | ハトの左側の路地にある鋼鉄の階段。眠っている猫を見つけ、そのすぐ下の段をクリックする |
| スピーディースケートボード（Speedy Skateboard） | 路地の突き当たり左端の水辺。水際に沿って探す |

| 濡れた犬（Wet Dog） | 左側のストリートダンサー付近の植え込み。ガイドの1つはバスステーション裏の植木鉢と報告している |
| スパイシードラムスティック（Spicy Drumstick） | チキンファストフード店の看板 — マスコットが掲げている |

### ハトとお気に入りの携帯電話

ハトは通りに放し飼いになっているわけではありません。ボードゲーム店の等身大パネル看板に印刷されています。地面ではなく看板を見てください。Into Indie Gamesは、右上のピザ店方面、マジシャンの近くに置いているとしており、これは同じクラスターと一致します。

お気に入りの携帯電話は、ハトの左側の路地にある鋼鉄の階段上のオレンジ色の携帯電話です。まず眠っている猫を見つけ、その真下の段をクリックします。Into Indie Gamesは逆方向からアプローチします。東へ進んで青いバスを目指し、その横にある階段付きの建物を見つけ、携帯電話を持ったぽっちゃりした猫を探します。

### スケートボード、肖像画、濡れた犬

スピーディースケートボードは、路地の突き当たり左端の水中でほとんど見えません。路地を左端まで進み、開けた舗装をクリックするのではなく水際をスキャンしてください。Into Indie Gamesは、南西の階段近くの川の中にあると説明しています。

不運な肖像画は写真ブースの外の地面に平らに置かれています。Into Indie Gamesでは、整備士の近くのカメラ店と説明されています。入口の真前の床をクリックしてください。

濡れた犬については、2つのガイドの見解が分かれます。Casual Game Guidesは左側のストリートダンサー付近の茂みの中に隠れていると報告し、Into Indie Gamesはバスステーション裏の植木鉢で昼寝していると報告しています。次へ進む前に両方の植え込みを確認してください。

### 屋台で見つかるもの：ドラムスティック、コーン、ゴールデンチケット

スパイシードラムスティックはチキンファストフード店の看板の一部です。マスコットが掲げている手を見てください。落としたコーンは桜の木の下のカップルの後ろのベンチにあります。Into Indie Gamesは代わりに、メイドのマスコット看板があるピンクの店を指し、そこではアイスクリームがマスコットの手の上にあります。

ゴールデンチケットは、屋台の屋根にあるウサギ像が持つ黄金の球の後ろです。下の人混みは無視し、中央の像に集中してください。Into Indie Gamesは同じ物体を、白いハト近くの巨大なウサギの像の上にあると説明しています。

## 風船の回収とAfrodite

風船の回収はストーリールートとは別の任意目標で、Casual Game Guidesはステージ周辺の8個の風船を求められると報告しています。メインアイテムとは独立して進行するため、風船を1個逃すだけで、ゴールデンチケットを提出した後でも完全クリアに届かなくなる可能性があります。

風船は最後の周回に取っておきましょう。左側の水辺と路地側からパンし、中央の店の看板を通り、右側の店先で終えます。

最後の風船について、プレイヤーが[Steamコミュニティの最後の風船に関する議論](https://steamcommunity.com/app/2101390/discussions/0/800090026542219500/)で具体的な風船を2つ記録しています：

- 1つの風船はドーナツ看板のリングの中に挟まっています。ユーザーSecretsは「丸いドーナツの中央」にあると説明しています。
- もう1つの風船はチキン看板の上にあります（ユーザーPinkyCharmsによる）。

同じスレッドのユーザーSkovdeのヒントは覚えておく価値があります。最後の風船は小道具の後ろに隠れるのではなく、看板やビルボードに溶け込んでいるため、見つからないように感じるのです。看板の中央やマスコットのアートを探索対象の表面として扱ってください。

ステージを離れる前に、ガチャポン店近くのバレリーナ型の低木の後ろにあるAfroditeを取っておきましょう。ストーリーの必須項目ではありませんが、通り過ぎやすいです。

## このレベルでアイテムを見逃し続ける理由

Lost and Found Co.は、看板の縁、棚の縁、窓枠、トレイ、引き出し、箱の中にオブジェクトを隠します。[Casual Game Guidesの一般的な攻略のヒント](https://casualgameguides.com/walkthroughs/lost-and-found-co)によると、What an Unlucky Dayではそのパターンが絶えず現れます。ハトはアートワーク、ドラムスティックはアートワーク、ゴールデンチケットは屋根の小道具の後ろです。

検索を短くする習慣をいくつか挙げます：

- **層ごとにスキャンする。** まずスカイラインと吊り下げられた小道具、次に看板とカウンター、最後に床の雑貨。
- **空白ではなく小道具をクリックする。** 隠された目標は、クリック可能なものの中や後ろに隠されています。
- **推測する前にズームする。** 小さなオブジェクトは、素早くクリックするよりもズームとパンの方がはるかに報われます。
- **ヒントは最後まで取っておく。** Jujuヒントは、ステージ全体がまだ未確認のときではなく、1つのゾーンの1アイテムに問題を絞り込んだときに最も効果を発揮します。

単一のアイテムではなくレベルの構造で行き詰まっている場合は、[Lost and Found Co.のSteamコミュニティガイドハブ](https://steamcommunity.com/app/2101390/guides/)に、プレイヤー作成の目標リスト、スクリーンショットマップ、Jujuの場所ガイドが集められており、照らし合わせて使えます。

## FAQ

**このLost and Found Co What an Unlucky Day攻略は100%クリアに十分ですか？**
メインストーリーの全アイテム、Afroditeのボーナス拾得物、風船目標をカバーしています。Casual Game Guidesは、ゴールデンチケットを完了した後でも風船を逃すと100%に届かない可能性があると指摘しているので、風船回収は最後に行ってください。

**What an Unlucky Dayには風船がいくつありますか？**
Casual Game Guidesは、任意の風船目標でステージ周辺の8個の風船を求められると報告しています。プレイヤーの報告では、少なくとも2つの具体的な場所が確認されています。ドーナツ看板のリングの中と、チキン看板の上です。

**What an Unlucky Dayのゴールデンチケットはどこにありますか？**
屋台の屋根にあるウサギ像が持つ黄金の球の後ろです。下の人混みではなく、像自体に集中してください。

**濡れた犬が見つからないのはなぜですか？**
公開されている2つのガイドの見解が分かれています。左側のストリートダンサー付近の茂みを確認し、次にバスステーション裏の植木鉢を確認してください。どちらも植え込みなので、通路ではなく葉の茂みをスキャンしましょう。
